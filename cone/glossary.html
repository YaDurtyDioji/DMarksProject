Access Network LU1
The network that physically connects an end system to its first (edge) router. Examples: DSL, cable, FTTH, Ethernet, Wi-Fi, 4G/5G.
Acknowledgment (ACK) LU3
A message from receiver to sender confirming successful receipt of data. TCP uses cumulative ACKs. UDP does not.
ADSL LU1
Asymmetric DSL — downstream faster than upstream. Uses existing telephone copper; speed depends on distance to exchange.
AIMD LU3
Additive-Increase Multiplicative-Decrease. TCP congestion control: grow cwnd linearly until loss, then halve it. Produces sawtooth pattern.
ALOHA LU6
Earliest random access protocol. Slotted ALOHA max efficiency = 1/e ≈ 37%. Pure ALOHA ≈ 18%.
Anycast LU5
Same IP advertised from multiple locations; BGP delivers to nearest instance. Used by DNS root servers and CDNs.
ARP LU6
Address Resolution Protocol — resolves local IPv4 address → MAC address. Broadcast request, unicast reply, cached with TTL.
Autonomous System (AS) LU5
A group of routers under one administrative control, identified by an AS number. Intra-AS routing uses OSPF; inter-AS uses BGP.
Bandwidth LU1
Raw transmission capacity of a link (bits/sec). Not to be confused with achieved throughput.
BGP LU5
Border Gateway Protocol — path-vector inter-AS routing protocol. Runs over TCP port 179. Policy-driven route selection.
AS-PATH (BGP) LU5
BGP attribute listing ASes traversed. Used for loop detection and route preference (shorter = preferred).
Broadcast LU6
One sender → all receivers on a link. Ethernet broadcast MAC = FF-FF-FF-FF-FF-FF.
Bufferbloat LU4
Excessive buffering causing persistent high latency. Solved with active queue management (AQM) like RED, PIE, CoDel.
CDMA LU1
Code Division Multiple Access — users share time+frequency via unique spreading codes. Suffers from near-far problem; power control needed.
CDN LU2
Content Distribution Network — geographically distributed servers caching content closer to users. Placement: "enter deep" (Akamai) or "bring home" (Limelight).
CIDR LU4
Classless Interdomain Routing — a.b.c.d/x notation. First x bits = network prefix. Enables route aggregation.
Circuit Switching LU1
Resources reserved end-to-end for the session (FDM/TDM). Predictable but wastes capacity when idle. Traditional telephony.
Congestion Control LU3
Protects the network by regulating sender rates based on perceived congestion. TCP uses cwnd + AIMD. Flow control protects the receiver (rwnd).
Cookie LU2
Small value stored by browser and returned with requests to identify sessions on stateless HTTP. Attributes: Secure, HttpOnly, SameSite.
CRC LU6
Cyclic Redundancy Check — polynomial division (XOR) by generator G. Very strong error detection. Used in Ethernet FCS (CRC-32).
CSMA/CD LU6
Carrier Sense + Collision Detection. Classic Ethernet. Listens, aborts on collision, uses binary exponential backoff.
CSMA/CA LU6
Carrier Sense + Collision Avoidance. Wi-Fi. Uses random backoff + link-layer ACKs + optional RTS/CTS because collisions can't be detected.
cwnd LU3
Congestion window — sender-side limit on unACKed data set by congestion control. Distinct from rwnd (receiver flow control).
DASH LU2
Dynamic Adaptive Streaming over HTTP — video split into chunks at multiple bitrates. Client picks best per chunk based on measured throughput.
DHCP LU4
Dynamic Host Configuration Protocol — auto-configures IP, mask, gateway, DNS. Uses DORA exchange over UDP 67/68.
DORA LU4
DHCP exchange: Discover → Offer → Request → Acknowledge.
Dijkstra's Algorithm LU5
Link-state shortest-path algorithm. Settles closest nodes iteratively. Used by OSPF. Complexity O(n²) naive, O(n log n) with heap.
DNS LU2
Domain Name System — translates names to IPs. Hierarchy: root → TLD → authoritative. Records: A, AAAA, NS, CNAME, MX. Runs over UDP 53.
Distance-Vector (DV) LU5
Decentralised routing: each router knows only neighbours' distance vectors. Uses Bellman-Ford. Prone to count-to-infinity. RIP is an example.
Encapsulation LU1
Each layer adds a header as data moves down the stack. Receiver strips headers moving up (decapsulation).
ECN LU3
Explicit Congestion Notification — routers mark packets instead of dropping. Sender reacts via ECE/CWR. Defined in RFC 3168.
Ethernet LU6
Dominant wired LAN technology. Frame: preamble + dst MAC + src MAC + type + data (46–1500) + CRC. Connectionless, unreliable at link layer.
Fibre to the Home (FTTH) LU1
Optical fibre to the home. Architecture: AON (active, dedicated) or PON (passive, shared). Highest residential speeds.
FIFO LU4
First-In-First-Out scheduling — packets transmitted in arrival order. Simple but no traffic differentiation.
Flow Control LU3
Protects the receiver from being overwhelmed. TCP uses rwnd advertised in every segment. Different from congestion control.
Fragmentation LU4
Splitting a datagram larger than the link MTU into fragments. Offset in 8-byte units. IPv4 routers may fragment; IPv6 routers do not.
Go-Back-N (GBN) LU3
Pipelined protocol with sender window N, receiver window 1. Cumulative ACKs. On timeout, resends missing packet and all subsequent ones.
Head-of-Line (HOL) Blocking LU4
A queued packet at the front of an input queue waits for a busy output, blocking other packets behind it even if their outputs are free.
HTTP LU2
HyperText Transfer Protocol — stateless request-response over TCP. Methods: GET, POST, PUT, HEAD, DELETE. HTTP/2 adds multiplexing; HTTP/3 runs over QUIC.
Hub LU6
Layer 1 (physical) device — broadcasts every incoming signal to all ports. Single collision domain. Obsolete; replaced by switches.
ICMP LU5
Internet Control Message Protocol — error reporting + diagnostics. Ping uses Echo Request (8) / Reply (0). Traceroute uses Time Exceeded (11).
IPv4 LU4
Internet Protocol version 4 — 32-bit addresses, 20-byte variable header, TTL, header checksum, fragmentation allowed.
IPv6 LU4
Internet Protocol version 6 — 128-bit addresses, fixed 40-byte header, no header checksum, no router fragmentation, no broadcast.
Link-State (LS) LU5
Routers flood link-state info; each builds a full topology map and runs Dijkstra. OSPF is a link-state protocol.
LTE LU1
Long-Term Evolution — 4G all-IP cellular architecture. UE, eNodeB, MME, HSS, S-GW, P-GW.
MAC Address LU6
48-bit flat link-layer address burned into NIC. Written as hex. Broadcast = FF-FF-FF-FF-FF-FF.
MIB LU5
Management Information Base — database of managed objects on a device, queried via SNMP.
MME LU1
Mobility Management Entity — 4G control plane element. Handles authentication, mobility tracking, tunnel setup.
MTU LU4
Maximum Transmission Unit — largest link-layer frame payload a link can carry. Ethernet = 1500 bytes.
NAT LU4
Network Address Translation — many private IPs share one public IP via port translation table. Pros: saves IPv4, hides hosts. Cons: breaks end-to-end, complicates P2P.
NETCONF LU5
Network Configuration Protocol — structured config over XML/TLS. Supports atomic commit + rollback. YANG models define structure.
OpenFlow LU4
SDN protocol between controller and switch. Flow table = match fields + counters + actions.
OSPF LU5
Open Shortest Path First — link-state intra-AS routing protocol. Uses Dijkstra inside an autonomous system. Supports areas, authentication, ECMP.
Packet Switching LU1
Data broken into packets, shared links dynamically. Store-and-forward at routers. Efficient for bursty traffic. Queues/loss possible.
Port Number LU2
16-bit identifier for a transport endpoint. HTTP=80, HTTPS=443, DNS=53, SMTP=25, DHCP=67/68.
Propagation Delay LU1
d/s — time for one bit to travel the physical link. Depends on distance, not packet size or link rate.
Queuing Delay LU1
Time waiting in a router output buffer. Grows sharply as traffic intensity La/R → 1.
QUIC LU3
Quick UDP Internet Connections — app-layer protocol over UDP. Combines transport + TLS. Per-stream multiplexing. Basis for HTTP/3.
RSA LU2
Public-key encryption algorithm. n=pq, z=(p-1)(q-1). Public=(n,e), private=(n,d). Used in TLS, PGP, IPsec.
rwnd LU3
Receive window — receiver-advertised free buffer space for TCP flow control. Distinct from cwnd (congestion control).
SDN LU5
Software-Defined Networking — separates control plane (logically centralised) from data plane (per-switch forwarding). OpenFlow is a common southbound protocol.
SMTP LU2
Simple Mail Transfer Protocol — pushes email over TCP port 25. Uses HELO, MAIL FROM, RCPT TO, DATA, QUIT.
SNMP LU5
Simple Network Management Protocol — over UDP. Operations: Get, GetNext, GetBulk, Set, Trap. Best for monitoring. Weaker for bulk config than NETCONF.
Socket LU2
Interface between an application process and transport layer. Identified by IP + port.
Selective Repeat (SR) LU3
Pipelined protocol with sender window N and receiver window N (buffers OOO). Individual ACKs, per-packet timers. Only resends the missing packet.
Stop-and-Wait LU3
Send one packet, wait for ACK before sending next. Simple but low utilisation on high-RTT links.
Switch (Layer 2) LU6
Forwards frames by MAC address. Self-learning (source MAC → port). Forward / Filter / Flood. Each port = own collision domain.
Subnet LU4
A group of interfaces that can reach each other without going through a router. Usable hosts = 2^(32-prefix) − 2.
TCP LU3
Transmission Control Protocol — reliable, ordered, connection-oriented byte stream. 3-way handshake, cumulative ACKs, flow + congestion control, full duplex.
Three-Way Handshake LU3
SYN (seq=x) → SYN-ACK (seq=y, ack=x+1) → ACK (ack=y+1). Establishes TCP connection.
Transmission Delay LU1
L/R — time to push all packet bits onto the link. Depends on packet size and link rate; independent of distance.
UDP LU3
User Datagram Protocol — connectionless, no reliability/ordering/congestion control. 8-byte header. Used by DNS, streaming, VoIP, gaming, HTTP/3.
VLAN LU6
Virtual LAN — logical partition of a switch into isolated broadcast domains. Access port (one VLAN) vs trunk port (multiple, 802.1Q tagged).
Wi-Fi (802.11) LU6
IEEE 802.11 WLAN. Uses CSMA/CA (collision avoidance). Access Point (AP) based. 2.4/5/6 GHz bands. Standards: 802.11n/ac/ax.
Work-Conserving LU4
A queuing discipline that never leaves the link idle if any packet is queued. RR and WFQ are work-conserving.
