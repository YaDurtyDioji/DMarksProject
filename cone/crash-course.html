LU1 — Internet, Wireless & Mobile
🎯 The One-Liner

The Internet is a network of networks that shares links on demand (packet switching) using a 5-layer stack. Wireless adds radio (shared, lossy) and mobility (handover).

📌 The 5 Things You MUST Know
  • Packet switching > circuit switching for bursty data because links are shared, not reserved.
  • 4 delays: Processing, Queuing, Transmission (L/R), Propagation (d/s).
  • 5-layer stack: Application → Transport → Network → Link → Physical.
  • Throughput = bottleneck link. The slowest link on the path caps everything.
  • 4G/5G: phone → base station → network core → internet. Handover = moving between towers.
💡 Killer Analogies
Packet switching = sharing pizza. Everyone grabs slices when they're hungry.
Circuit switching = reserving the whole pizza whether you eat it or not. Wasteful if you're not hungry.
Transmission delay = pushing the whole caravan through the tollbooth.
Propagation delay = how long the first car takes to drive to the next tollbooth.
Bigger caravan = longer transmission. Faster road = same propagation (distance doesn't change).
CDMA = a crowded room with everyone speaking a different language. You can pick out your language if you know the code. The near-far problem = the person next to you shouting louder than everyone else.
🧮 If they ask you to calculate…
dtrans = L / R (bits ÷ bits per second)
dprop = d / s (s ≈ 2×10⁸ m/s)
Total = proc + queue + trans + prop
Always ×8 first if packet size is in bytes.
⚠️ Exam Traps
Don't say propagation depends on packet size. It doesn't. It depends on distance.
Don't say the internet has 7 layers. OSI has 7, the Internet uses 5.
🧠 Mnemonic
"Please Queue The Pies" — Processing, Queuing, Transmission, Propagation.
"Up End Made Hot Slow Packs" — UE, eNodeB, MME, HSS, S-GW, P-GW (4G elements).
LU2 — Application Layer
🎯 The One-Liner

Applications talk through sockets (IP + port). HTTP is stateless; cookies and caches add state. DNS is the phonebook. CDNs move content closer to users.

📌 The 5 Things You MUST Know
  • TCP vs UDP: TCP is reliable and ordered. UDP is fast and "fire and forget".
  • HTTP is stateless. Cookies are how the server remembers you.
  • DNS translates names → IPs. Records: A (IPv4), AAAA (IPv6), MX (mail), CNAME (alias), NS (nameserver).
  • Cache = your desk drawer. Cached copy is faster than re-fetching from origin.
  • CDN = a library in every city. User gets content from nearest copy.
💡 Killer Analogies
HTTP = you asking a waiter for food. Stateless = waiter forgets you after every order. Cookie = your loyalty card — now the waiter knows you're a returning customer.
DNS = phonebook. You know the name "google.com", but your browser needs the phone number (IP address). DNS looks it up.
DASH = a chef giving you the video in slices at different quality levels. Your player picks the best quality your connection can handle per slice, not per whole video.
🧮 If they ask you to calculate…
Non-persistent HTTP (per object): 2 RTT + transmission
Persistent + pipelining: ~2 RTT total (one connection)
Example: 1 page + 8 objects, RTT = 50 ms
→ Non-persistent (no parallel) = 18 RTT = 900 ms
→ Persistent + pipelining ≈ 3 RTT = 150 ms
⚠️ Exam Traps
DNS uses UDP port 53 for normal queries. TCP only for zone transfers or huge replies.
Cookies ≠ cache. Cookies identify YOU. Caches store CONTENT. Different jobs.
🧠 Mnemonic
DNS records: "A AAA NS CNAME MX" = "Ah, Another Name Change, Mate?"
DORA the DHCP Explorer: Discover, Offer, Request, Acknowledge.
LU3 — Transport Layer
🎯 The One-Liner

TCP is the reliable, ordered delivery guy. UDP is the fast, unreliable postcard. Flow control protects the receiver; congestion control protects the network. AIMD = probe, back off, probe again.

📌 The 5 Things You MUST Know
  • TCP 3-way handshake: SYN → SYN-ACK → ACK.
  • Sequence number = byte position. ACK = next expected byte, not last received.
  • Flow control (rwnd) ≠ congestion control (cwnd). One protects your friend, the other protects the road.
  • Slow Start doubles every RTT. Congestion Avoidance +1 MSS per RTT. On timeout → cwnd = 1. On 3 dup ACKs → halve, then fast recovery.
  • GBN vs SR: GBN resends the whole window. SR resends only the missing one.
💡 Killer Analogies
Flow control = your friend's tiny stomach. You stop serving when their plate is full (rwnd = 0).
Congestion control = the restaurant is packed. Everyone slows down (cwnd shrinks) so the kitchen can keep up.
AIMD = see-saw with a bungee cord. Slowly climb up (additive increase). On loss, snap back down by half (multiplicative decrease). Repeat forever.
GBN = "Go Back and Nuke the whole window." If packet 3 is lost, resend 3, 4, 5, 6 — everything.
SR = "Select just the missing one and Repeat." Only 3 gets resent. 4, 5, 6 are buffered.
🧮 If they ask you to calculate…
Stop-and-wait utilisation = (L/R) ÷ (RTT + L/R)
EstimatedRTT = (1−α)·EstRTT + α·SampleRTT (α=0.125)
DevRTT = (1−β)·DevRTT + β·|Sample−Est| (β=0.25)
TimeoutInterval = EstRTT + 4·DevRTT
⚠️ Exam Traps
ACK number = next byte expected. If you receive bytes 1000–1499, ACK = 1500. Not 1499.
UDP has a checksum. It detects errors, but does NOT retransmit.
🧠 Mnemonic
"Say Yes, Say Yes & Cheer, Acknowledge" — SYN, SYN-ACK, ACK.
"Some Animals Feed Regularly" — Slow start, Avoidance, Fast retransmit, Recovery.
LU4 — Network Layer: Data Plane
🎯 The One-Liner

Forwarding is per-router and fast (local). Routing is network-wide and slow (decisions). IPv4 is 32-bit; IPv6 is 128-bit. Longest prefix match wins. DHCP = DORA. NAT = many private → one public.

📌 The 5 Things You MUST Know
  • Forwarding (nanoseconds) ≠ routing (seconds).
  • Longest prefix match: the most specific route wins. Default = 0.0.0.0/0.
  • DHCP DORA: Discover, Offer, Request, Acknowledge.
  • Subnetting: usable hosts = 2(32−prefix) − 2.
  • SDN = match-plus-action. Same table can act as router, switch, firewall, or NAT.
💡 Killer Analogies
Forwarding = a postman at one street. He looks at the envelope and picks the next street.
Routing = the map on the post office wall. It decides all the paths for all mail.
Longest prefix match = the most specific rule wins. If a rule says "all roads" and another says "this street", the street rule wins.
NAT = a hotel reception desk. Guests have room numbers (private IPs). Reception has one public street address and routes mail to the right room using a log.
DHCP = getting a hotel room. Discover (you ask), Offer (they say "room 42"), Request (you accept), Acknowledge (they confirm).
🧮 If they ask you to calculate…
Host bits = 32 − prefix
Usable = 2host bits − 2
/24 = 254 · /25 = 126 · /26 = 62 · /27 = 30 · /28 = 14 · /29 = 6 · /30 = 2

VLSM rule: Biggest subnet first. Smallest block that fits (hosts + 2).
⚠️ Exam Traps
Forgetting −2 for network + broadcast. Don't allocate small first — you get gaps.
IPv6 routers don't fragment. They send "Packet Too Big" (ICMPv6).
🧠 Mnemonic
"DORA the DHCP Explorer" — Discover, Offer, Request, Acknowledge.
"I Should Open Portals" — Input, Switch fabric, Output, Processor (router parts).
LU5 — Network Layer: Control Plane
🎯 The One-Liner

OSPF = link-state inside an AS. BGP = path-vector between ASs, driven by policy. Link-state = you have the map. Distance-vector = ask neighbours. SDN = one brain controlling many switches.

📌 The 5 Things You MUST Know
  • Link-state = full topology, Dijkstra. OSPF is link-state.
  • Distance-vector = only neighbours' info, Bellman-Ford. RIP is DV.
  • Count-to-infinity = DV loop problem. Poisoned reverse helps a bit.
  • BGP route selection: Local-Pref → shortest AS-PATH → closest NEXT-HOP.
  • ICMP: ping (echo request/reply), traceroute (TTL expiry).
💡 Killer Analogies
Link-state = everyone gets a full map of the road network. Each driver finds their own fastest route.
Distance-vector = each driver asks their neighbours for directions. "I don't know the way to Durban, but Piet said it's 200 km from his house."
Count-to-infinity = "I know a shortcut!" But the shortcut goes through the person who told you. You loop forever.
BGP = international diplomacy. It's not about "fastest path" — it's about "which providers will actually carry our traffic, and which we'll carry for them."
Anycast = many shops with the same phone number. Your call goes to the nearest one. DNS root servers use this.
🧮 If they ask you to calculate…
Bellman-Ford: Dx(y) = min over neighbours v of { c(x,v) + Dv(y) }
Dijkstra: start at source, settle closest unfinalised node, relax its neighbours.
Example: A—B (4), A—C (9), B—C (2)
Path A→C via B = 4 + 2 = 6 (better than direct 9).
⚠️ Exam Traps
BGP is NOT distance-vector. It is path-vector.
iBGP is not "inside an AS like OSPF." It's how external BGP routes are distributed inside an AS.
🧠 Mnemonic
"LS = Look at whole map. DV = Depend on neighbour rumours."
"Local Athletes Hop" — Local-Pref → AS-Path → Hot-Potato (BGP selection order).
LU6 — Link Layer & LANs
🎯 The One-Liner

The link layer moves frames one hop at a time. CRC is the strongest error check. ARP maps IP → MAC. Switches learn MACs. VLANs partition a switch. Ethernet is wired; Wi-Fi is CSMA/CA.

📌 The 5 Things You MUST Know
  • CRC > Checksum > Parity (detection strength).
  • CSMA/CD (wired, detect) vs CSMA/CA (wireless, avoid).
  • MAC = 48 bits, flat. Broadcast = FF-FF-FF-FF-FF-FF.
  • ARP: broadcast request, unicast reply, cached with TTL.
  • Switch: learn source MAC → forward known / flood unknown.
💡 Killer Analogies
CRC = doing long division in XOR. Append zeros, divide by generator, remainder = checksum. Receiver divides again — if remainder is zero, no error detected.
Switch = smart postman inside one building. He remembers who lives in each apartment (source MAC + port). Known destination → deliver directly. Unknown → shout into every apartment (flood). Same-port destination → ignore (filter).
ARP = "Who has 192.168.1.1?" You shout into the room (broadcast). The owner raises a hand (unicast reply). You write their name down (cache).
VLAN = dividing one big open-plan office into separate rooms with separate walls. Same building, but you can't hear the other room's gossip.
🧮 If they ask you to calculate…
CRC: D = 101110, G = 1001 (r=3)
1. Append 000 → 101110000
2. Divide using XOR (no borrows)
3. Remainder R = 011
4. Transmit D + R = 101110011
Receiver: divide received bits by G. Remainder zero = no detected error.
⚠️ Exam Traps
XOR ≠ normal subtraction. No borrowing.
ARP for remote host: you ARP for the gateway MAC, not the remote server's MAC.
VLAN alone ≠ security. You still need inter-VLAN routing with ACLs.
🧠 Mnemonic
"Please Check Carefully" — Parity, Checksum, CRC (weakest → strongest).
"Cats Randomly Turn" — Channel partitioning, Random access, Taking turns (multiple access classes).
Wired = "Can See My Colliding Dog". Wireless = "Can't See My Cat Anywhere".

The 5 Secrets of Exam Marks
  1. Use the scenario. Mention the company, the users, the numbers, the constraints. Generic answers lose application marks.
  2. Match the verb. "Define" = 1 line. "Explain" = cause and effect. "Evaluate" = strengths, weaknesses, judgement.
  3. Show your formula work. Method marks are real. Even if your final number is wrong, showing steps earns marks.
  4. Draw a diagram where possible. Labelled diagrams earn marks in long questions.
  5. Manage time. ~1.2 minutes per mark. If a question is worth 20 marks, budget ~24 minutes. Move on if stuck.
